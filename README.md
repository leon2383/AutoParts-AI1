# AutoParts AI V1 – iPhone
Öffne `index.html` in einem Browser oder veröffentliche den Ordner auf einem statischen Webhost (z. B. GitHub Pages).

Die Anwendung ist komplett clientseitig: kein eigener Server und keine laufenden Kosten.
Daten werden per localStorage auf dem Gerät gespeichert.

Wichtig:
- Die eingebauten Fahrzeug-/Artikel-/Preis-/Bestandsdaten sind DEMO-/Eigenkatalogdaten.
- Es gibt bewusst keine erfundene VIN-Auflösung.
- Für echte Vollabdeckung braucht V1 später rechtmäßig nutzbare Fahrzeug- und Artikeldaten.
- Händler-Livepreise/-Lagerbestände können nicht seriös ohne deren Datenquelle automatisch garantiert werden.
- Eine optionale Ollama-Einstellung ist vorbereitet; die iPhone-App kann nicht selbstständig einen lokalen PC erreichen, wenn dieser nicht im gleichen Netz erreichbar ist und die Schnittstelle CORS/Netzwerkzugriff erlaubt.
